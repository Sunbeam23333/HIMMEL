# HIMMEL banner

`himmel-hero.png` is an AI-generated, original fan illustration featuring Himmel
from *Frieren: Beyond Journey's End*. It is decorative, not a scientific figure
or benchmark example. It does not imply endorsement by the character's rights
holders or by NeurIPS. Character rights remain with their respective owners;
the repository's code license does not grant rights to third-party characters.

The banner was generated with Codex's built-in image-generation tool using the
project's previous poster portrait as a character and palette reference. The
tool did not report a model identifier. Its generation prompt is recorded in
`hero-prompt.txt`.
